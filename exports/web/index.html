📐 Architect export

offline-ready
Bundle of construction zones + urban zoning + flood + climate + hillshade. Open in QGIS / ArcGIS / AutoCAD Map 3D, or save as DWG with one click.
GeoJSON ≈ 0.7 MB (Asunción) / 3.3 MB (nacional). Plan PDF genera una página imprimible del mapa actual (Ctrl+P → Guardar como PDF).

📐 De GeoJSON a DWG (4 clics)

  1. Abrí QGIS Desktop (gratis: qgis.org).
  2. Capa → Añadir capa → Añadir capa vectorial… → elegí architect_export_asuncion.geojson.
  3. Hacé clic derecho sobre la capa → Exportar → Guardar objetos como…
  4. Formato: AutoCAD DWG (DXF si tu AutoCAD es muy viejo). CRS: EPSG:32721 (UTM 21S — el que usan los catastros en Paraguay).
💡 Tip: en AutoCAD, los polígonos llegan como hatch boundaries. Para que se vean como zonas, ejecutá BPOLY dentro del polígono. Si necesitás las ordenanzas como texto dentro del DWG, exportá también el CSV de zonas (próximamente).
🟢 Alternativa sin QGIS: en AutoCAD Map 3D o Civil 3D, MAPIMPORT → formato GeoJSON → seleccionar archivo. Funciona en AutoCAD 2018+.
⚠ Datos preliminares. Para Asunción centro hay 4 zonas (Ord. 246/94). Cobertura nacional depende de Lucía + ordenanzas municipales.
