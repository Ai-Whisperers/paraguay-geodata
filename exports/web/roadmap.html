Roadmap

Qué viene y por qué. Por orden de prioridad y de impacto.

🚀 Q3 2026 — En curso

  • Property panel v2 — popup mejorado con precio/m², días en mercado, comparables. (Aug 2026)
  • API autenticada — para planes Pro, con auth tokens y rate limiting. (Sep 2026)
  • Email alerts — "avisame cuando baje el precio" con Mensajería de PY. (Sep 2026)
  • MapBiomas Paraguay — deforestación histórica superpuesta. (Sep 2026)
  • NASA FIRMS — fuegos activos últimas 24h. (Sep 2026)

📦 Q4 2026 — Próximo

  • Contornos — 1m, 5m, 10m sobre el DEM. (Oct 2026)
  • Recorrido 3D — Cesium viewer para lotes. (Oct 2026)
  • Comparables — auto-suggest "casas similares en este barrio". (Nov 2026)
  • Notary directory — abogados y escribanos por depto. (Nov 2026)
  • Ciudadano — comparador con municipios vecinos. (Dic 2026)

🔭 2027 — Visión

  • Multi-país — modelo similar para Argentina, Uruguay, Bolivia.
  • AI undertraining — modelo propio para predecir tendencias.
  • Suscripción para equipos — admin, SSO, billing portal.
  • Data marketplace — datasets de terceros a través de Paraguay Geodata.
